# User Registration System

A simple and responsive user registration web application built using **HTML**, **CSS**, and **Java**.  
Users can create an account by entering their details, and the application validates and processes the registration form.

## 📌 Project Description

This project demonstrates a basic registration system where users can sign up by providing information such as:

- Full name
- Email address
- Username
- Password
- Confirm password

The front end is created using HTML and CSS, while Java handles the backend logic, form processing, validation, and registration functionality.

## 🚀 Features

- Responsive registration form
- Clean and user-friendly interface
- Client-side form layout using HTML
- Styled with CSS
- Java-based backend for registration processing
- Basic input validation
- Password confirmation check
- Easy to customize and extend

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML | Structure of the registration page |
| CSS | Styling and responsive design |
| Java | Backend logic and form handling |
